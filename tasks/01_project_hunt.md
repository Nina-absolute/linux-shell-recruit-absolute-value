# Task 01 — Project Hunt

**难度：★☆☆☆☆**

项目编号藏在 `workspace/` 中某个位置。已知保存它的文件内容包含 `PROJECT_ID`，而且它可能不是默认可见的文件。

## 任务

1. 找到项目编号，把编号本身写入 `output/01_project_id.txt`。
2. 假设当前目录是 `workspace/src/utils/`，把从这里访问该文件的相对路径写入 `output/01_relative_path.txt`。

## 可能需要了解

`pwd`、`ls`、`cd`、`find`、`grep`、`cat`、隐藏文件、相对路径与绝对路径。

完成后运行：

```bash
./check.sh 01
```
