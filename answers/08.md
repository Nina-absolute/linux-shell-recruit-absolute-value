# Task 08 Answer

**问题：为什么 Shell 中 `$var` 和 `"$var"` 有时会得到不同结果？**

**答案：**

在 Shell 中，`$var` 和 `"$var"` 的区别在于是否进行“分词（Word Splitting）”。

- `$var`（不加双引号）：Shell 会对变量值进行分词。如果变量值包含空格、制表符或换行符，它们会被当作分隔符，把变量值拆分成多个独立的参数。例如 `FILE="My Report.txt"`，`echo $FILE` 会输出 `My Report.txt`，但 `cp $FILE /destination/` 会被拆成 `cp My Report.txt /destination/`，导致 `cp` 认为要复制 `My` 和 `Report.txt` 两个文件。

- `"$var"`（加双引号）：Shell 不会对变量值进行分词，整个变量值作为**一个整体**传递。例如 `cp "$FILE" /destination/` 会正确地把 `"My Report.txt"` 当作一个文件名。

==因此，在处理文件名、路径等可能包含空格的字符串时，必须使用双引号。==
