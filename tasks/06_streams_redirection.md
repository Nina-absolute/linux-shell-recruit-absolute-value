# Task 06 — Streams & Redirection

**难度：★★★☆☆**

运行 `./tools/check-project`。它会同时产生正常输出和错误输出。

## 任务

1. 把 stdout 保存到 `output/06_stdout.txt`。
2. 把 stderr 保存到 `output/06_stderr.txt`。
3. 再运行一次，使正常输出既显示在终端中，又保存到 `output/06_tee.txt`。

可能需要：`stdout`、`stderr`、`>`、`2>`、`|`、`tee`。

```bash
./check.sh 06
```
